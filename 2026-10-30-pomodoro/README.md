# 沉浸式番茄钟 · pomodoro

一个「会呼吸」的番茄钟。

**解决的问题**：大多数番茄钟要么太花哨（一堆图表、打卡、成就），要么太简陋（一个倒计时）。
真正需要的是打开就能专注、结束会提醒、数据还在的一个人。

## 怎么用

直接双击 `index.html` 即可（零依赖、零配置、不联网）。

```bash
# 或者起个本地服务
python3 -m http.server 8000
# 打开 http://localhost:8000
```

建议按 `F` 全屏，然后把窗口放到第二个屏幕 / 边上，专注时别看它。

### 快捷键

| 键 | 作用 |
|---|---|
| `空格` | 开始 / 暂停 |
| `S` | 跳过当前阶段（跳过专注不算番茄） |
| `R` | 重置（回到第 1 轮专注） |
| `F` | 全屏 |
| `,` | 打开设置 |

### 设置项（右上角齿轮）

- 专注时长：默认 25 分钟（1–120）
- 短休息：默认 5 分钟
- 长休息：默认 15 分钟
- 长休息间隔：默认每 4 轮一次
- 结束提示音：可关

配置和统计数据都保存在浏览器 `localStorage`，刷新不丢。

## 实现要点

- **时间用截止时间戳算，不用 `setInterval` 累加**：`remain = deadline - Date.now()`，
  后台标签页被浏览器节流也不会走偏。切回页面时自动校正。
- **圆环进度**用 SVG `stroke-dasharray/offset`，比 canvas 更省事、还能加 `drop-shadow` 发光。
- **呼吸感**：背景是一层 `radial-gradient` + `::after` 的 `breathe` 关键帧缓慢缩放，
  专注（红紫）/ 短休息（绿蓝）/ 长休息（蓝紫）三套配色随阶段切换。
- **提示音用 WebAudio 现场合成**：专注完成是上行琶音 C-E-G-C，休息结束是两声下行三角波。
  不依赖任何音频文件，音色偏「温柔的提示」而不是刺耳闹钟。
- **数字风格**：等宽数字（`tabular-nums`），秒跳变时钟面不抖。
- **完成瞬间**：白屏闪一下（90ms）+ 声音 + toast + 标签页标题同步倒计时。

## 已知限制

- 提示音需要浏览器已交互过（用户点击过页面），这是浏览器的自动播放策略，无法绕过。
- 后台标签页时 rAF 会被节流，"今日专注分钟数" 的累计可能略有偏差；番茄完整计数不受影响。
- 数据只存在当前浏览器，换设备/清缓存会丢。不做账号不做云同步，是刻意为之。
