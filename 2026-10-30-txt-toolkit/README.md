# 文本手术刀 · txt-toolkit

一个小到不能再小的文本清洗台。

**解决的问题**：从 PDF、网页、微信、Excel 里复制出来的中文文本，往往被塞满了
乱七八糟的换行、全角空格、中文之间的空隙。扔进编辑器手动删，几十行还行，几百行就崩溃。

**做法**：把最烦人的那几条清洗规则一次性打包成「一键清洗」，顺手给出字符数、中文字数、
行数、段落数和预计阅读时长。

## 用法

直接双击 `index.html`，或者：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 清洗规则

| 规则 | 说明 |
|---|---|
| 全角/不间断空格归一 | `U+3000`、`U+00A0` → 普通空格 |
| 清除隐形字符 | 零宽空格、BOM 等 |
| 中文换行粘回 | 汉字被 PDF 断行的地方重新接上 |
| 中文间空格删除 | `中 文` → `中文` |
| 行尾空白清理 | 去掉每行尾部空格/制表符 |
| 连续空行压缩 | 3 个以上换行压成 1 个空行 |
| 全角标点后空格 | `，` 后面的多余空格删掉 |

## 特点

- 纯前端单文件，零依赖，不联网，不上传任何数据
- 可离线使用，直接发文件给别人也能用
- 顺手按钮：去首尾空白 / 删空行 / 复制结果
