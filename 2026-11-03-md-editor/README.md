# 墨池 · Markdown 实时编辑器

> Day 04 · 2026-11-03

## 解决什么问题

想随手写点 Markdown（笔记、README、周报），又不想为此打开 VS Code、装 Typora 或登录某个在线编辑器。
墨池是一个**双击 `index.html` 就能用**的本地 Markdown 编辑器：左边写，右边即时排版，
内容只存在你浏览器的 localStorage 里，**不联网、不上传、不登录**。

## 怎么用

1. 双击 `index.html`（或 `python3 -m http.server` 起个静态服务后打开）
2. 直接开写。首次打开会有一段示例文档，清空即可
3. 也可以把 `.md` 文件**直接拖进窗口**，或点「导入 md」
4. 写好的东西：
   - 自动保存到浏览器本地（刷新不丢）
   - 「导出 .md」把源码存成文件
   - 「导出 HTML」生成**单文件、可离线分享**的带样式网页
   - 「复制」把 Markdown 源码塞进剪贴板

### 三个视图

- **写作**：只剩编辑器，宽度收窄到 820px，专注模式
- **分栏**：默认，左右滚动同步
- **阅读**：只剩渲染结果

底部「☰ 大纲」打开侧边大纲：列出所有标题，点一下平滑跳转并高亮闪烁一下。
3 秒找不到自己写到哪了的时候，这个功能真的很救命。

## 实现要点

- **渲染**：`marked` v15（GFM 表格 / 任务列表 / 删除线 / 围栏代码），
  [本地内置]（`marked.min.js`，39 KB，来源 `marked@15.0.12`，MIT License），离线可用
- **安全**：
  - `renderer.html` 把所有原始 HTML **转义成文本**，`<script>` / `<img onerror>` 不会执行
  - `renderer.link` 只放行 `http(s):` / `mailto:` / `#` / 相对路径，`javascript:` 链接被清空
  - 外链统一加 `target="_blank" rel="noopener noreferrer"`
- **性能**：`input` 事件里不直接渲染，用 `requestAnimationFrame` 合帧，同样一帧内的多次输入只渲染一次
- **保存**：`localStorage` 写入做了 400ms 防抖，右上角闪现「已保存到本地」
- **统计**：中文按**字**计、英文按**词**计，阅读时长按中文 350 字/分 + 英文 200 词/分估算
- **大纲**：正则扫 `#` 标题，但会数前面的 ``` 数量跳过代码围栏里的「假标题」
- **无框架、无构建**：纯原生 JS，`app.js` 一个 IIFE，打开即用

## 已知限制

- 不做 Markdown 语法的**输入高亮**（编辑器是原生 `<textarea`，这样才零依赖、大文件不卡）
- 中文按字计数，标点也计入「字数」——和大多数编辑器一致，但没有剔除标点的选项
- 本地存储约 5 MB 上限，超长文档可能保存失败（会提示「保存失败」）
- 不支持图片拖拽上传（可写标准 `![](url)` 外链）
- 大纲用「标题文本」匹配跳转，两个同名标题会跳到第一个
