# 声景 · Soundscape

> 六种环境音，自由叠成你此刻想要的那片空气。

一个**不下载任何音频文件**的白噪音混音器：雨、海浪、风、篝火、咖啡店、琴音，
全部由 Web Audio API 在浏览器里实时合成。拖动六条推子就能混出你自己的专注/助眠声场，
自带六个预设场景、频谱可视化、睡眠定时渐弱。

## 解决什么问题

想专注、想放松、想睡觉的时候，去音乐 App 找白噪音：
- 要会员、有广告、断网就用不了；
- 固定曲目听腻了，同一段雨声循环三遍就出戏；
- 想"雨 + 一点琴"这种组合，绝大多数 App 不给调。

这个作品把这些都去掉了：**打开即用、可任意叠加、永不重复、完全离线**。

## 怎么用

双击 `index.html`（或起个静态服务）即可。

```
python3 -m http.server 8941 --directory 2026-11-04-soundscape
```

然后浏览器打开 http://127.0.0.1:8941

### 操作说明

1. 点 **▶ 开始聆听**（浏览器要求用户手势后才能出声）。
2. 拖动六张卡片的滑块调各轨音量 —— **多个音轨可同时开启**，会实时混音。
3. 或者直接点下方 **预设场景** 一键组合：雨夜书房 / 海边小屋 / 咖啡馆角落 / 露营篝火 / 深度专注 / 睡前。
4. **睡眠定时**：15 / 30 / 60 / 90 分钟，到点前 12 秒音量线性渐弱后自动停止。
5. 点卡片左上角图标 = 单轨静音开关；鼠标悬停卡片滚动滚轮 = ±4 微调。

### 键盘快捷键

| 按键 | 作用 |
|---|---|
| `空格` | 播放 / 暂停 |
| `1`–`6` | 开关对应音轨（雨/浪/风/火/咖啡/琴） |
| `M` | 总音量静音切换 |

## 实现要点

### 1. 零素材：三种噪声基底全部数学生成

| 声音 | 合成方式 |
|---|---|
| 雨 | 粉噪音 → 400Hz 高通 + 6.5kHz 低通，叠加 45 次/秒的随机宽带雨点脉冲 |
| 海浪 | 棕噪音 → 0.9 Q 低通，用 0.085Hz + 0.033Hz 双 LFO 同时调制**音量**与**滤波截止频率**（12 秒一个浪，浪高不重复） |
| 风 | 棕噪音 → 带通（中心 420Hz 缓慢漂移），0.023Hz 阵风包络调制振幅 |
| 篝火 | 棕噪音 → 900Hz 低通作火焰低鸣，叠加 ~9 次/秒的高通短脉冲噼啪（振幅做平方分布 → 多数小、偶尔爆） |
| 咖啡店 | 粉噪音 → 800Hz 带通 + 2.6kHz 低通，0.19Hz 缓慢起伏模拟人声嘈杂的波浪感 |
| 琴音 | C 五声音阶三角波 + 二次谐波正弦，指数衰减包络，程序生成的卷积混响（2.6s 脉冲响应） |

粉噪音用 Paul Kellet 的 economical filter（7 个一阶极点近似 1/f 谱），棕噪音用积分滤波（1/f²）。
生成后**统一峰值归一化到 0.95**，所以不同噪声音量观感一致。

### 2. 消除循环接缝

噪声缓冲 6 秒，首尾各 0.5 秒做**交叉淡化**（`out[i] = a[i]*w + a[n-fade+i]*(1-w)`），
循环时不会有周期性"咔哒"声 —— 这是白噪音网页最常翻车的地方。

### 3. 雨滴间隔是泊松过程

真实雨滴不是等距的。用 `-ln(1-U)/λ` 生成指数分布间隔（λ = 30 次/秒），
振幅用 `0.25 + 0.75·U^2.2` 让小雨滴占多数、偶尔一颗大的。测试中 CV = 1.00，完全符合指数分布。

### 4. 音量曲线用平方

`gain = (volume/100)²`。人耳对响度的感知接近对数，线性推子在低端变化太猛、高端又没感觉；
平方曲线让推子行程更贴合感知。所有增益变化走 `setTargetAtTime(…, 0.08)` 平滑，避免爆音。

### 5. 播放/暂停的淡入淡出

暂停时先把总线音量拉到 0、各轨 `setTargetAtTime(0, 0.06)` 淡出，420ms 后才真正
`stop()` 并断开节点，避免"咔"的截断声。播放时反向操作：先建节点静音，再整体淡入。

### 6. 可视化

AnalyserNode（fftSize 1024）取 512 个频点，降采样成 48 根柱，驱动背景光晕与粒子雨。
粒子生成速率与实际音频能量挂钩 —— 静音时不掉落，有声音才"下雨"。

## 已知限制

- 依赖 Web Audio API，现代浏览器都支持；**不支持 IE 与部分极老旧 WebView**。
- iOS Safari 静音开关打开时，Web Audio 仍可能无声（系统限制，非代码问题）。
- 琴音的琶音是随机游走，不保证"好听"，只是保证**不刺耳**（五声音阶天然无半音冲突）。
- 移动端 `setInterval` 在后台会被节流，导致雨滴/噼啪层稀疏；切回前台自动恢复。基础噪声层用 AudioBuffer loop，不受影响。
- 未做录音/导出功能，纯实时播放。

**关键结论**：低频(100–500Hz)/高频(2–3.8kHz) 功率比依次为

- 白噪音确实平坦（比值≈1，理论值 1）
- 粉噪音符合 1/f（10 倍频程内功率增约 10 倍）
- 棕噪音符合 1/f²（10 倍频程内功率增约 100 倍，实测 100.55）
