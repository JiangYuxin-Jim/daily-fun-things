# 2048 · 数字炼金术

复刻经典 2048，但把「能跑起来」升级成「玩得舒服」：
**带撤销、带 AI 教练、带最高分记忆的版本**。零依赖、纯本地、无网络请求。

## 解决什么问题

原版 2048 网页常见三个痛点：

1. **手滑没法回头** —— 一步走错整局报废。本版本支持撤销最近 30 步。
2. **不知道怎么下** —— 本版本内置一个「AI 教练」，实时给出四个方向的评分条，
   告诉你此刻走哪边赢面最大，也可以拿它学 2048 的思路。
3. **做到 2048 就没了** —— 达成 2048 不会强制结束，弹出提示后可以继续冲 4096 / 8192。

## 怎么用

```bash
cd 2026-11-06-2048
python3 -m http.server 8931        # 或直接双击 index.html
# 浏览器打开 http://127.0.0.1:8931/
```

| 操作 | 键位 |
|---|---|
| 移动 | 方向键 / WASD / HJKL / 手指滑动 |
| 重开 | `R` 或「新游戏」按钮 |
| 撤销 | `U` 或「撤销」按钮 |
| AI 提示 | 点「🤖 提示」切换开关 |

## 实现要点

- **`core.js` 是纯函数引擎**，不碰 DOM，浏览器用 `<script>` 引入、Node 用 `require()`，
  同一份代码既跑游戏也跑单元测试（`/tmp/t1.js` 那种测试就是直接 require 它）。
- **移动算法统一化**：四个方向全部转换成「向左滑」——左右/上下先按需反转，滑动完再反转回来，
  合并位置索引也同步映射回去。这样合并规则只写一遍，不会出现「向左对、向下错」的经典 bug。
- **一条行合并规则**：`2,2,2 → 4,2`（不是 8），相邻两块相等才合并，一个块一回合只参与一次合并。
- **AI 用 1-ply 期望值**：对每个合法方向试走，再对结果里的最多 12 个空格按
  90% 出 2 / 10% 出 4 的概率抽样评估，取平均分。评估函数 = 空格数 + 单调性 + 平滑度 + 最大块贴角奖励。
  死局给 -90 万分，所以 AI 会拼命保住空格。
- **动画不用 canvas**：每个方块是一个绝对定位 div，靠 CSS `transition: left/top` 平滑移动，
  新块 `.pop` 弹入、合并块 `.merge` 放大脉冲，均为纯 CSS keyframes。
- **撤销用一个 30 步的栈**，存 `{board副本, score}`，所以撤销后分数、棋盘完全还原。
- 最高分存 `localStorage['2048-best']`。

## 已知限制

- 撤销只保留最近 30 步（避免栈无限增长）。
- AI 是单步前瞻 + 启发式，不是蒙特卡洛搜索；实测能稳定到 1024，
  运气好能到 2048，但不像顶尖 AI 那样能打到 8192 以上。
- 不含无限撤销、不含「回放」功能。
- 移动端依赖触摸滑动；超小屏幕（<320px）方块字号会偏挤。
