# 记忆棱镜 · Memory Prism

> Day 10 · 2026-11-08 · 游戏 / 纯前端零依赖

翻牌配对，几乎人人都写过。所以这一版不拼「有」，拼**手感和可验证性**。

## 解决什么问题

**想在浏览器里安静地玩一局记忆翻牌，不被广告、内购和「下载 App」打断。**

双击 `index.html` 就能玩，断网能玩，成绩只存在你自己的浏览器里。四档难度之间有真实的策略差异（不是只改牌数），极限关还带 3 分钟倒计时。

## 怎么玩

- **翻牌**：点牌 / 触屏点牌。翻两张，牌面相同就消除并加分，不同就扣分、连击清零
- **四档难度**（键盘 `1`~`4`）
  - `1 轻松` 4×3 / 6 对 / 揭晓 3 次
  - `2 标准` 4×4 / 8 对 / 揭晓 1 次
  - `3 硬核` 5×4 / 10 对 / 无揭晓
  - `4 极限` 6×6 / 18 对 / 无揭晓 + **180 秒倒计时**，超时直接结束
- **👁 揭晓**（`空格`）：全场亮牌 1.4 秒，代价是 `-120` 分且次数有限；揭晓期间随便点一张牌 = 立刻收起（不浪费步数）
- **连击**：连续配对成功时，第 n 对有 `100 + (n-1)×50` 分，音高也随连击升半音，最多升 7 个半音
- **星级**：通关时失误 ≤1 次 → ★★★，≤ 对数 → ★★，其余 ★；一次没配错且每张牌只翻一遍，弹窗会额外盖一个「完美记忆」章
- **重开**：`R`；`Esc` 关弹窗
- 切到别的标签页时，正在进行的揭晓会**自动收起**——防止「离开时偷看」

## 实现要点

### 1. 引擎是纯函数，时钟和随机数都靠注入

`core.js` 不碰 DOM、不读 `Date.now()` / `Math.random()`：

- `createGame({ level, seed })` —— 随机源是可复现的 mulberry32 PRNG，**同种子必出同一副牌**
- `flip(state, id)` → `{ ok, state, event, why }`，`event ∈ flip|match|miss|peek-cancel`，原 state 永不修改
- `peek(state, ms)` / `tick(state, ms)` —— 「揭晓」用**逻辑时间**表达（`peekUntil`），所以动画到期这种异步行为在测试里完全确定，不需要 `setTimeout` 垫片
- `checkInvariants(state)` —— 6 条不变量（每种牌偶数张、pairId 成对、牌数=对数×2、已配对必成对、pairsFound 一致、flipped ≤1）

### 2. 配对判定「当场结算」而不是挂计时器

翻第二张时立刻判定并返回，所以状态机里不存在「翻开两张、等 500ms 再收回」的中间态。
收回动画交给 `app.js` 的 `busyUntil` 视觉锁（360ms），引擎完全不用管动画。少一个状态，就少一类 bug。

### 3. 开局保证「至少一对相邻」

纯随机会出现「开局一张都蒙不到」的挫败感。建局后用 `hasAdjacentPair()` 校验，不合格就换种子重洗（最多 200 次）。

### 4. 视觉：CSS 3D 翻转，零图片资源

牌背是一个 conic-gradient 光斑 + 内描边；翻转是 `rotateY` + `preserve-3d` 的 `backface-visibility`；配对成功加绿色辉光和 `.gone` 缩放淡出。音效用 WebAudio 现场合成（三角波翻牌、正弦配对、锯齿配错），没有音频文件，也不会有加载失败。

## 已知限制

- **配对判定是即时的**：翻开第二张的瞬间就判定，没有「停留一会儿让你记」的悬念期。这是刻意的简化（少一个中间态），但也让节奏比传统翻牌更利落
- 最高分只按难度分别记录在本机 `localStorage`，换浏览器/清缓存即丢；没有排行榜、没有账号
- 牌面用 emoji，不同系统的 emoji 字形会不一样（不影响功能，只影响观感）；牌数固定为难度预设，不能自定义
- 极限关的倒计时使用真实时间累计，标签页在后台时每帧最多推进 200ms —— 所以「切走 = 计时变慢」在极限关是**真实存在**的（算是给玩家的后门，没堵）
- 触屏没有实现「滑动选择」，只有点击


两个方向的结论都成立：
- **会记的人**平均翻牌数正好等于「对数×2」——每张牌只翻一遍，说明引擎没有隐藏的信息泄漏，也没有多余的翻牌；
- **不记的人**平均失误 27.2 次（多翻 54 次），说明失败路径是真的通的，不是「随便点也能过」。
