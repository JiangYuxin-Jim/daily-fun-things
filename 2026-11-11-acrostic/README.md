# 藏头诗机 · acrostic

把名字、祝福、任何几个字，写成一首像模像样的小诗。

## 解决什么问题

想给朋友/家人/自己写个藏头诗，要么自己憋半天憋不出来，要么上网找的生成器要联网、要注册、动不动就成了广告页。
这个工具**双击 `index.html` 就能用，纯本地、零依赖、不联网**，输入 2-8 个字立刻出诗，还能换韵、换版式。

## 怎么用

1. 直接双击 `index.html`（或 `python3 -m http.server` 起个静态服务）
2. 输入框写 2-8 个字，比如「今天很好」「江雨欣」
3. 选五言 / 七言，回车或点「作 · 诗」
4. 句尾带金色下划线的字 = 同韵字；红色首字 = 你的藏头
5. 「换一版」重新生成，「复制诗句」一键拷走；勾上「自动换一版」每 6 秒刷新一稿

命令行也能用：

```bash
node -e "const C=require('./core.js');console.log(C.compose('江雨欣',{len:7}).poem)"
```

## 实现要点

- **纯函数引擎 `core.js`**：不依赖 DOM，浏览器与 node 两用，方便单测。
- **双字词库优先**：内置 140 个高频诗性双字词（清风、明月、流水、野渡……）。生成时优先与上一字组成词，所以句子读起来是「词接词」而不是随机堆字。
- **束搜索（beam search）**：每步保留 12 条候选，评分 = 成词 +3 / 句尾合韵 +4 / 意象实词 +0.35 / 前瞻能引出下一个词 +0.8；排序前加微小随机扰动，保证每次换版都不一样。
- **押韵**：14 个宽韵部（今音近似归并），偶数句句尾强制押韵；末字若被前面用过会触发重试，最多 6 轮，杜绝「首尾同字没法押韵」的翻车。
- **全诗不重字**：所有已用字进全局集合参与扣分，藏头字本身也算已用。
- **可复现**：xorshift 伪随机 + FNV-1a 字符串哈希，同一 `(文字, 字数, 韵部, seed)` 必得同一首诗，方便测试。

## 已知限制

- 用的是兴趣向小字库（363 字 / 140 词），不是真实语料训练，**不保证语义通顺、不保证符合平仄格律**——它是「有点意象的小诗」，不是古诗。
- 藏头字若是生僻字或非意象字，它所在那一句会相对平淡。
- 单字藏头会报错提示，需要 ≥2 字。
- 宽韵按今音近似归并，和《平水韵》不是一回事。

## 实测验证

```
node --check core.js && node --check app.js      # 语法通过
node test.js                                     # ALL OK ✅
  · 7 组藏头 × 五言/七言 × 2 个 seed = 28 首
  · 藏头首字全部正确、句长全部正确
  · 押韵命中 48/48（偶数句）
  · 成词率 62%（相邻两字构成词库中的词）
  · 可复现性：同 seed 同诗；换 seed 必不同
  · 异常路径：空输入 / 单字 / 9 字 均正确拦截
python3 -m http.server 8931 --directory .        # index.html 200，core.js 200
```
