# 弹球 · 打砖块（breakout）

> Day 14 · 2026-11-12

经典打砖块的重制版：**一个能真的接住球、每次击球都有手感反馈的版本。**

## 解决什么问题

打砖块是「一小时能写完、但写好很难」的典型：多数实现都能动，但玩起来会崩——

- 球速一快就**穿砖块**（每帧位移大于砖厚，直接跳过去）
- 球卡在几乎水平的角度上来回弹**几十秒不动**
- 打挡板永远是同一角度，**没有操作空间**
- 打砖块就是无脑加分，**没有连击爽感**

这个版本把这几件事逐个处理掉了，并且在浏览器里跑得稳（无后端、无依赖）。

## 怎么玩

双击 `index.html`，或用任意静态服务器打开：

```bash
cd 2026-11-12-breakout
python3 -m http.server 8931
# 浏览器打开 http://127.0.0.1:8931/
```

**操作**

| 动作 | 键鼠 | 触屏 |
| --- | --- | --- |
| 移动挡板 | `←` `→` / `A` `D` / 鼠标移动 | 手指拖动 |
| 发球 | `空格` / 点击场地 | 点一下 |
| 暂停 | `P` | 「暂停」按钮 |
| 重开 | `R` | 「重来」按钮 |

**玩法要点**

- 击球点越靠近挡板**边缘**，反弹角度越刁钻（最多 ±60°）
- 每次击球都会给球**加 1.5% 速度**——越打越紧张
- **连击**：连续击砖不断，得分 10 × min(连击, 8)；打挡板会清空连击
- 砖块颜色 = 血量：灰(1) / 金(2) / 绿(3)，砖上有数字角标
- 掉球扣 1 命，3 命用完结束；过关奖励 `100 + 50 × 剩余命数`
- 6 种关卡图案轮换：金字塔 / 满铺 / 棋盘 / 菱形 / 拱门 / 随机，每 2 关加一行砖
- 最高分与最远关卡存在 `localStorage`

## 实现要点

- **`core.js` 纯引擎**：`(world, dt)` 进，`world` 出，不碰 DOM。浏览器和 node 都能跑，所以测试是直接跑真引擎，不是跑仿制逻辑。
- **子步进防穿透**：每帧按位移量切成 ≤ `r/1.5` 的小步，高速球也不会跳过砖块。测试里用 3000 px/s（正常速度的 10 倍）垂直穿越 200 次，0 次穿透。
- **圆-矩形碰撞**：先做 AABB 快速剔除，再用最近点求法线；圆心落在矩形内部时退化为「选最近边」的法线，避免出现 NaN。
- **挡板反弹**：按击中点相对挡板中心的偏移量 `rel ∈ [-1,1]` 映射到 ±60° 的发射角，同时保持速度模长（每击 ×1.015）。
- **角度保底**：每帧检查速度方向，垂直分量小于 sin(10°) 就强行抬起来，杜绝水平死循环。
- **动画层**：命中粒子（带重力）、屏幕震动（衰减 shake）、命中白光 flash、连击 toast、未发球时的呼吸箭头。
- **渲染**：逻辑坐标固定 600×760，画布按容器等比缩放并居中，`devicePixelRatio` 上限 2（性能与清晰度平衡）。

## 已知限制

- 无音效（为了保持零资源文件；WebAudio 合成可以加，本版未做）
- 没有道具系统（加长挡板、多球等），刻意没做——先把基础手感打磨干净
- 关卡是**程序化生成**的图案轮换，不是手工设计的关卡表
- 最高分只存在本机 `localStorage`，换浏览器就没了
- 触屏只支持「拖动」，没有做虚拟摇杆
