# 提示词工坊 · Prompt Forge

> Day 15 · AI Prompt 优化器（2026-11-13）

## 解决什么问题

大多数人写提示词的毛病是固定的：太短、没有角色、没说输出格式、塞满「请问/谢谢」、用「更好一点」这种没法执行的模糊词。结果就是模型自由发挥，来回改十遍。

Prompt Forge 是一个**纯本地、零依赖、不联网**的提示词体检 + 重写工具：粘进去一段话，立刻告诉你扣分在哪、怎么改，并生成一份结构化改写稿，现场能看逐行差异。

## 怎么用

```bash
# 方式一：直接打开
open index.html        # 双击也行

# 方式二：起本地静态服务
python3 -m http.server 8931
# 浏览器访问 http://127.0.0.1:8931/
```

操作：

1. 把提示词粘进左边的框（或点「填入示例」看效果）
2. 点 **⚡ 开始锻造**（或用 `Ctrl/Cmd + Enter`）
3. 右边看分数环 + 扣分项和改法；下面对比「差异」与「优化稿」
4. 角色 / 受众 / 篇幅 / 输出格式 可以自定义，勾「严格模式」会追加「不许寒暄」约束
5. 点「复制优化稿」直接拿去用

## 实现要点

- **规则引擎**（`engine.js`，UMD，浏览器与 Node 共用）：
  - 12 条规则：空内容 / 过短 / 无角色 / 无动作动词 / 无输出格式 / 无约束 / 无背景 / 模糊词 / 客套话 / 任务过多 / 无示例 / 问号过多
  - 每条规则带扣分权重，从 100 分往下扣，再对有结构（含列表行）、篇幅适中（40–600 字）的稿子加回少量分
  - 模糊词与客套话用词典 + 正则匹配，命中后会在建议里点名具体是哪些词
- **优化生成**（`improve`）：先剥离客套话，再按 `角色 / 任务 / 背景 / 要求 / 输出格式 / 示例` 六段模板重组；哪些段落该出现，取决于诊断出的缺陷（例如有模糊词才追加「禁止模糊表述」那条要求）
- **中文 token 估算**：汉字按 1 token、其余按 4 字符 1 token，够用不花钱
- **行级 diff**：LCS 动态规划；当两稿行数乘积 > 40 万时自动降级为「全部视为新增」，防止大文本卡死页面
- 单页应用，无构建步骤，`engine.js` 直接 `<script>` 引入

## 实测验证

```bash
node --check engine.js && node --check test.js
node test.js
```

自检覆盖 7 组断言（`test.js`）：

- 空输入 → 0 分、命中 `empty`
- 烂提示词「请问你能帮我优化一下这个东西吗，让它更好一些，谢谢」→ **37 分**，正确识别模糊词 + 客套话
- 结构完整的好提示词 → **100 分 / S 级**
- `improve` 后：角色写入、六段结构齐全、客套话被清除、分数提升
- 严格模式追加约束行
- `diffLines('a\nb\nc','a\nx\nc')` 的 same/del/add 三组结果与预期一致
- token 估算：「你好世界」= 4

静态服务探测：`python3 -m http.server` 下 `index.html` 与 `engine.js` 均返回 **200**。

## 已知限制

- **规则驱动，不是模型驱动**：它能抓「结构缺陷」，但不懂语义。词库之外的模糊表达（比如「稍微润色下别提那么生硬」）它识别不出来。
- 优化稿的「背景」段是**占位符**，需要使用者自己填——工具不知道你的业务上下文，瞎编更糟。
- 只在中文 + 少量英文关键词上做过验证，纯英文提示词的角色/格式识别率会下降。
- diff 按行比较，段落内部的小改动会整行显示为删除+新增，不会做字符级高亮。
- 没有历史记录 / 本地存储，刷新即清空（刻意为之，避免在公共机器上留内容）。
