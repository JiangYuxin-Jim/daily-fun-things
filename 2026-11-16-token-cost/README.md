# Token 账房 · token-cost

> 粘贴一段文本，立刻知道它值多少钱。

## 解决什么问题

用大模型时最模糊的一个数字就是「token」和「钱」：

- 这段 prompt 大概多少 token？中文和英文差多少？
- 同一个活儿，GPT / Claude / Gemini / DeepSeek 各要花多少钱？差几倍？
- 上了 prompt caching 到底省了多少？
- 我这个用法一个月账单会是多少？

Token 账房把这些一次性算清：**估算 token → 逐模型比价 → 月度账单推演 → 一键复制账单**。
全部纯本地计算，文本不出浏览器。

## 怎么用

双击 `index.html` 即可（零依赖、零网络）。

1. **① 估算 token**：把文本粘进左侧框，实时显示 token / 汉字 / 英文 / 标点 / 行数。
   右侧选模型（价格自动填充，也可手改），填输出长度、调用次数、缓存命中量、预算，立刻得到单次成本、合计、缓存省下的钱和「预算能跑几次」。
2. **② 比价表**：同一份输入下所有模型按单次成本从低到高排序，带横向条形图看倍数差。点任意一行即可切换为当前模型。
3. **③ 月度账单推演**：选一个场景预设（日常问答 / 长文写作 / 代码审查 / RAG / Agent），或自己填每日用量，看每天、每月、折人民币的花费，以及「换成最便宜的模型能省百分之多少」。
4. 点「复制账单」或按 `Ctrl/⌘ + Enter`，把结果贴给同事。

## 实现要点

- **`engine.js` 是纯函数模块**：不碰 DOM，浏览器里挂到 `window.TokenCost`，Node 里 `require` 即可，前后端共用同一套算法。
- **token 估算按字符分类累加**：
  - CJK 区（汉字/假名/谚文）= 1 token/字（主流 BPE 对中文约 1.0~1.3）；
  - 英文/标识符按连续串 `ceil(长度/4)` 计；
  - 数字串、标点各算 1；
  - 空白按每 4 个 1 token 计（缩进/换行确实吃 token）。
- **成本模型**：`(新鲜输入×输入价 + 缓存输入×缓存价 + 输出×输出价) / 1e6 × 次数`，缓存 token 自动截断到不超过输入总量，无缓存概念的模型自动退回原价。
- **反推预算**：给定金额 `floor(预算 / 单次成本)`，单次为 0 时返回 `Infinity` 而不是崩溃。
- 金额自适应小数位：小于 1 美分给 5 位小数或科学计数法。

## 已知限制

- token 数是**启发式估算**，不是真 tokenizer。与真实值通常相差 ±15%，长短文本越极端偏差越大。
- 模型价格是 2026 年的**参考值**，随时可能变；页面里价格框可随时手改，不要把它当合同价。
- 人民币按固定 `1 USD = 7.2 CNY` 折算，没接实时汇率。
- 缓存命中率在月度推演里是「整体命中率」，不区分不同服务商的缓存过期策略（通常 5 分钟 ~ 1 小时）。
- 批量输入 / 文件上传没做，长文本靠粘贴。

## 实测验证

```
$ node --check engine.js      # 语法通过
$ node test.js
✅ 47 项断言全绿
示例：16 汉字 → 16 tokens
示例：GPT-5.1 1000 in / 500 out → $0.00625
```

自检覆盖：空/null 输入、纯中英与混排估算、成本精确值、多次调用线性、缓存折价与超额截断、无缓存价回退、预算反推、非法负数输入、金额格式化、模型价格表完整性、一万字长文、纯空白计费。

页面用 `python3 -m http.server` 起服务探测：`index.html` 与 `engine.js` 均返回 200。
