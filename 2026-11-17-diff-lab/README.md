# 对照台 · diff-lab

> 两份文本的差异，一眼看清。纯本地跑，不上传一个字。

## 解决什么问题

改稿、改配置、对两版 PR 说明、比两个 JSON 输出——你经常需要回答「这两份到底差在哪」。
但系统自带的 `diff` 只会吐一堆 `<>` 符号，网页上的在线工具又要你先把内容传到别人服务器上。

对照台把这件事做成一页纸：**左边贴旧版、右边贴新版，差异立刻高亮**，行内级的改动也会精确到具体哪个字（中英文混排都能正确切）。

## 怎么玩

直接用浏览器打开 `index.html`（零构建、零依赖、断网可用）。

1. 左右两个框分别粘贴**旧文本**和**新文本**（也可以点右上角「示例」先看效果）
2. 差异自动出现，输入时实时重算（260ms 防抖）；`Ctrl/⌘ + Enter` 立即比较
3. 顶部三个视图切换：
   - **并排**：左旧右新，行内字级高亮（红色删除 / 绿色新增）
   - **统一 diff**：标准 `git diff` 格式（`--- a/` `+++ b/` `@@ -1,3 +1,4 @@`），一键复制
   - **概览**：相似度百分比、增删行数、改动规模判定（"改动很小" / "大改" / "基本重写"）
4. 比较粒度可切 **按行** / **按字符（段落模式）**；可勾选「忽略大小写」「忽略行尾空白」
5. 点 **⇄ 交换** 快速反向看差异

## 实现要点

- **算法**：完整实现的 Myers O(ND) 最短编辑路径算法（不是简单的单行 LCS），记录了每一步的 `V` 快照做回溯，得出最短的编辑脚本。
- **自校验**：自检脚本用 300 组随机字符串，把编辑脚本**重放**还原出原文（必须逐项相等），同时用 DP 求 LCS 长度交叉验证 `eq` 数 —— 保证是最短路径而非"看起来对"。23 项断言全绿。
- **中文友好切词**：英文按连续单词聚块、中文逐字、标点单独成 token，所以「今天天气**真**好 → 今天天气**很**好」只标一个字，而不是整行。
- **行内二次差分**：并排视图里把「删一行 + 加一行」配成一行，再对这两行做字级 diff，得到 `<del>/<ins>` 高亮。
- **性能**：2000 行 / 20 处改动 3ms 出结果（Myers 的复杂度随差异量而非总行数增长）。
- **统一 diff 输出**：自己实现了 hunk 分组与上下文行（默认 3 行），输出和 `git diff` 同构，可直接当补丁阅读。
- 所有渲染走 `textContent` / 转义后再拼 HTML，不执行粘贴内容里的任何东西。

## 已知限制

- 按行 diff 的复杂度与**差异量**相关：两份完全不同的超长文本（万行级）会很慢，建议先按段落切片再看。
- 「按字符（段落模式）」的改动块是按**顺序配对**行（第 i 旧对第 i 新），不跑行对齐，适合连续改写的段落。
- 忽略空白只支持行尾空白，不支持「忽略全部空白」。
- 无三栏合并（merge conflict）视图，只做对比不做合并。
- 不处理二进制文件 / 图片比较。
