# 粒子宇宙 · particle-cosmos

> 一个可以用手指/鼠标「搅动」的实时引力星云。零依赖，双击 `index.html` 就跑。

## 解决什么问题

不是工具，是玩具 —— 但玩具里藏着真东西：**N 体引力仿真的数值稳定性**。
粒子之间的真实引力（软化 1/r²）天生容易“炸锅”（数值发散），这里用三件事把它摁住了：
软化核、外围回复力、硬限速。所以它既能一直转下去，也能随手拖一下就变形。

## 怎么玩

| 操作 | 效果 |
|---|---|
| 在画布上 **拖动 / 滑动** | 搅拌星云，移动越快推力越大，同时留下一道光迹 |
| **双击 / 双击点按** | 打击点：把周围粒子炸开 |
| **空格** | 暂停 / 继续（暂停后可以静止观察结构） |
| **R** | 重置为一团新的初始星云 |
| 右侧 **引力 G** | 0 → 3.0，调到 0 星云会慢慢摊开，调高会抱成一团 |
| 右侧 **漩涡** | -100 → 100，正负值反转旋转方向 |
| 右侧 **拖尾** | 4 → 60，越小越干净，越大越像长曝光星轨 |
| 右侧 **数量** | 120 → 900 粒子，实时增减（上限按性能给） |
| **配色** | 四套色板循环：深空 / 余烬 / 生物荧光 / 超紫外 |
| **流星** | 从边缘射入三颗大质量亮粒子，会明显扰动整团 |

## 实现要点

- `cosmos.js` 是**纯物理引擎**，不碰 DOM，所以能在 Node 里直接 `require` 跑测试。
  - `createParticles(n, seed)`：用 mulberry32 可复现随机数，在圆盘内均匀撒点（`r = sqrt(u)` 保证面积均匀），
    初速度取切向（角动量），质量随半径增加 —— 近似一个自引力盘而不是一团散沙。
  - `step(particles, opts)`：软化引力（`d² + soft²`）+ 极轻阻尼 + **只在外围生效的回复力** + 外围硬限速。
    前两个保证有结构，后两个保证任何滑块参数下都不发散。
  - `stir()`：鼠标冲量，二次衰减（`1 - d/R`），半径外完全不受影响。
  - `stats()`：动能 / 质心 / 最大半径，喂给 HUD。
- 渲染：Canvas 2D + `globalCompositeOperation = 'lighter'`，每帧用半透明底色铺一层做**拖尾**，
  粒子亮度跟着速度走（越快越亮），所以星云一直是“活”的。
- 主循环固定 **2 个子步**、`dt = 0.011`，与屏幕刷新率解耦，60Hz 和 120Hz 手感一致。
- 跑远的粒子会被拉回原点附近（软回收），不会因为一次猛搅就永久少掉一批。

## 已知限制

- O(n²) 暴力求引力。900 粒子 = 每步 ~81 万次相互作用 × 2 子步，中低端手机会掉帧；
  真要更多粒子得换 Barnes-Hut 四叉树。
- 没有真正的“碰撞合并”，粒子互相穿过。
- 暂停时 HUD 的能量数值不刷新（只在帧计数归零时采样）。
- 颜色只在切配色时重铺，单个粒子不会随速度变色。
- `index.html` 里的光迹是直接画在主画布上的：极端快速乱划时会有轻微拖影残留，靠拖尾淡出清掉。

## 实测验证

阶段一（push 前一次性）：

1. `node --check cosmos.js` → 通过
2. `node test.js` → **13 项断言全绿**：随机数可复现、粒子初值有限且在界内、圆心受力对称抵消、
   两粒子在引力下靠近（1.0000 → 0.9998）、600 步长跑无 NaN/Inf 且 `maxR = 4.15`（未发散也未塌缩）、
   搅拌只影响半径内粒子、质心计算正常
3. 静态服务探测：`index.html` / `cosmos.js` / `test.js` 均返回 **200**
