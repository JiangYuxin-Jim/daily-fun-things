# 极光场 · Aurora Field

> Day 23 · 2026-11-22 · 程序化生成的会呼吸的北境夜空

## 解决什么问题

动态极光壁纸/背景常见于视频素材站，但体积大、要版权、不能参数化。
这个作品用**可复现的噪声场**实时算出极光：没有一张图片素材、没有 WebGL，
纯 Canvas 2D 逐像素计算，随时改活跃度/速度/暖度，一键存成高清 PNG 当壁纸。

## 怎么用

直接双击 `index.html`（零依赖、离线可用）。或者：

```bash
cd 2026-11-22-aurora
python3 -m http.server 8943
# 浏览器打开 http://127.0.0.1:8943
```

| 操作 | 效果 |
|---|---|
| 预设按钮（经典极光 / 暴风 / 静谧 / 紫罗兰 / 深夜低光） | 一键切换整套参数 |
| **活跃度** | 极光帘幕的亮度与厚度 |
| **速度** | 时间流速，0 = 定格 |
| **暖度** | 从青绿逐渐转向紫粉 |
| **清晰度** | 渲染分辨率倍率（左低右高）；低 = 更省电、更柔，高 = 更通透 |
| **暂停 / 空格** | 定格当前帧 |
| **换一片天** | 重掷种子，换一套形态与星空 |
| **存图** | 以 2 倍尺寸重绘一帧并下载 PNG |
| 拖动画面上下 | 让极光带整体起伏（种子偏移） |

## 实现要点

1. **值噪声 + FBM**：`hash2`（`Math.imul` 保持 32 位整数语义）→ 双线性插值 + smoothstep →
   多倍频叠加得到分形噪声。同一 seed 结果完全一致，方便复现与测试。
2. **极光场函数** `auroraField(u,v,t,seed)`：
   - 用 FBM 抖动出一条**竖向概率带** `center`，再叠加两条正弦波让它像被风吹动；
   - 以带中心做高斯衰减（宽度本身也由噪声决定，所以帘幕宽窄不一）；
   - 乘上**横向细丝**噪声明暗，得到经典的「帘幕」竖条纹；
   - 乘 `(1-v)^1.6` 高度衰减，越靠地平线越淡。
3. **调色**：四段色标（深幽绿 → 荧光绿 → 青 → 紫）线性插值，暖度整体抬红降绿；
   与夜空底色用**屏幕模式**做加性混合，避免生硬边界。
4. **性能**：按 `quality` 降采样渲染到低分辨率 `ImageData`，由 CSS 拉伸放大，
   再叠 CSS 暗角 + 极淡噪点，柔光感更强且几乎免费；星星层预渲染到离屏 canvas，逐帧 `lighter` 叠加闪烁。

## 已知限制

- 纯 CPU 逐像素算，1080p 高质量档在低端机可能掉到 30fps 以下——把「清晰度」调低即可。
- 极光形态由噪声参数决定，不能像真实极光那样物理模拟地磁活动。
- 存图时不包含星星层与暗角，是「干净的极光场」。
- 拖动只是种子偏移，不是真正的手势物理。

## 实测验证

```
node --check aurora.js && node --check test.js   # 语法通过
node test.js                                     # 18 项断言全绿
  - 随机源 ∈ [0,1) 且同种子可复现
  - valueNoise / fbm 值域与确定性
  - 场值全域无 NaN/Inf、存在亮区、地平线比天顶暗
  - 调色低/高亮分布、暖度抬红通道
  - 64×40 整帧：像素数、alpha 全不透明、非纯黑、< 200ms
  - 时间推进时亮度确实变化
python3 -m http.server 8943 → index.html 200, aurora.js 200
```
