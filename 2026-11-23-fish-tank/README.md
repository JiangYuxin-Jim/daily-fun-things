# 桌面虚拟鱼缸 · desktop fish tank

一个挂在屏幕上发呆的虚拟鱼缸：鱼群自己游、自己抢食、自己变胖变饿，水质还会因为你喂太多慢慢变浑。

## 解决什么问题

不是工具，是**注意力休息站**。写代码写累了抬头看一眼鱼，比刷手机回血。

## 怎么玩

| 操作 | 效果 |
|---|---|
| 点水面任意位置 | 撒 4 粒鱼食，附近的鱼会游过来抢 |
| 点鱼身上 | 摸一下这条鱼，冒爱心，鱼会怯生生蹿一下 |
| 按 `F` 或点「🌾 投食」 | 撒一把鱼食（14 粒） |
| 「＋ 放鱼」 | 加一条新鱼（上限 24 条） |
| 空格 / 「⏸ 暂停」 | 暂停模拟 |
| 「隐藏面板」 | 只剩鱼，安静挂着 |

左上角实时显示鱼群数量、水温、水质和水质进度条。喂太多 → 水质下降 → 水变浑变绿。

打开方式：直接双击 `index.html`，零依赖零配置。

## 实现要点

- **群游算法**：分离（Separation）+ 对齐（Alignment）两个力，配上手写噪声漫游和「偏好的水深」，比完整 Boids 更像真正的散养鱼
- **觅食**：饥饿度 > 0.18 时找最近的一粒食，距离 < 320px 才追，追到嘴边长一半身长内就吃掉
- **边界**：软推力把鱼挡回来，再有一道 clamp 硬兜底，鱼永远不会穿出水缸
- **速度控制**：有上限（躲食时 1.9 倍）也有下限（避免漂成一坨静止），朝向用最短角差平滑跟随速度
- **生态循环**：喂食带来杂质 → 水质下降 → 视觉上水变绿变浑；沉底超过 6 秒的鱼食会融化并继续增加杂质
- **程序化美术**：水草、气泡、微尘、光柱、沙底、玻璃反光全部 Canvas 2D 现画，**零图片素材**
- **可测试架构**：`tank.js` 不给 `canvas.getContext` 也能跑（headless 模式），核心模拟脱离浏览器验证

## 自检

```bash
node --check tank.js
node selftest.js
```

`selftest.js` 用假 canvas 驱动真实模拟，覆盖：初始状态、边界约束、觅食成功率、120 秒长时模拟的数值稳定性（NaN/Infinity）、速度上限、水质衰减、摸鱼命中检测、容量上限、暂停行为。

实测结果：16 项全部通过，120 秒长时模拟无 NaN、无出缸、最大速度 21.5 px/s。

## 已知限制

- 鱼食只做下沉 + 轻微横向摆动，没有洋流
- 没有繁殖/死亡逻辑（可加：水质 < 0.3 持续太久鱼会生病）
- 鱼是 2D 侧视，没有前后景深度分层
- 手机端指针事件可用，但小屏 UI 面板会挡一部分水面
