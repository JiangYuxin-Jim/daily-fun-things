# 像素工坊 · Pixel Studio

Day 25 / 2026-11-24

一个小巧但真的能用的像素画编辑器：在一个带网格的画布上点格子画画，旁边有个「蹦跳预览」实时把你画的小人弹起来给你看，满意了一键导出 8 倍放大的 PNG。

## 解决什么问题

想要一个**打开就能画**的像素画工具：不注册、不联网、不做多余的事。很多在线像素编辑器要么功能堆得很满要学，要么导出的图很小没法直接用。这里只保留画像素真正需要的几件事，并且导出的图直接可用（×8 最近邻放大，无模糊）。

## 怎么用

1. 直接用浏览器打开 `index.html`（纯前端，无需服务器）。
2. 选颜色 → 选工具 → 在格子上点/拖。
3. 右边的「蹦跳预览」会实时展示成果，按 **空格** 暂停/播放。
4. 点「导出 PNG（×8）」下载；点 💾 存工程 JSON，📂 可再载入继续改。

### 工具与快捷键

| 工具 | 快捷键 | 说明 |
|---|---|---|
| 画笔 | `B` | 拖动自动补点，不断线 |
| 橡皮 | `E` | 或直接**右键**擦除 |
| 填充 | `G` | 扫描线洪水填充，闭合区域内填充 |
| 直线 | `L` | Bresenham，拖拽时实时预览 |
| 方框 | `R` | 只画边框，拖拽实时预览 |
| 取色 | `I` | 从画布吸取颜色 |

- `Ctrl/⌘ + Z` 撤销，`Ctrl/⌘ + Shift + Z` 重做（保留最近 60 步）
- `Ctrl/⌘ + 滚轮` 缩放视图
- **镜像对称**：左右同时画，画对称角色很方便
- **抖动阴影**：自动在像素右下补一格暗色，制造体积感
- 尺寸按钮在 8 / 16 / 24 / 32 / 48 / 64 之间切换，已有内容按最近邻缩放保留

## 实现要点

- **`pixcore.js` 是纯算法层**，零 DOM 依赖：图像用一个 `{w,h,data:Uint8ClampedArray}` 表示，坐标计算、Bresenham 直线、方框轮廓、扫描线洪水填充、最近邻放大/缩放、base64 存档编解码全在这里。正因为不碰 DOM，它可以在 Node 里直接跑自检。
- **`studio.js` 是界面层**：只负责指针事件、渲染、预览动画与导出，算法一律调 `PixCore`。
- **撤销栈**存完整像素快照（16×16 也就 1KB，够用且实现简单可靠）。
- **崩跳预览**：用 `requestAnimationFrame` 驱动，垂直位置取 `|sin(t)|` 做弹跳，再用 `sin(2t)` 做挤压/拉伸（squash & stretch），配合地面椭圆阴影 —— 这是让静态像素画「活过来」的关键手感。
- 导出用 `scaleNearest` 手动放大后 `putImageData` + `toBlob`，保证放大后边缘干净不糊。

## 已知限制

- 单图层，无图层概念（做简单的角色/道具完全够）。
- 没有选区移动、复制粘贴功能。
- 抖动阴影是固定右下方向的简单处理，不是完整的抖动明暗算法。
- 撤销栈上限 60 步。
- 如果浏览器禁用下载，导出会静默失败（无提示）。
