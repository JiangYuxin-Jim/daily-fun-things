# 人生刻度 · Life in Weeks

## 解决什么问题

大多数人不知道自己的时间到底还剩多少「单位」。直接说「还有 50 年」没有体感，
但这个工具会说：**你还有 50 个夏天、625 次满月、5276 个周末**。

把一辈子摊成一张格子纸 —— 一格一周，涂过的就是走过的。
不是要吓人，是想让人把「以后」换成「现在」。

## 怎么用

双击 `index.html` 即可，无需服务器、无网络请求。

1. 填出生日期，选一个预期寿命（默认 80 岁）
2. 点「开始」
3. 输入会记在 `localStorage`，下次打开自动重现；点「清除」删掉

## 实现要点

- `life.js` 是**纯函数算法层**，不碰 DOM，可直接在 Node 里跑测试
- 天数用「本地零点的日历日差」计算（`Math.round(diff / 86400000)`），
  避开夏令时/DST 造成的 23/25 小时误差
- 闰日生日（2/29）自动顺延到 3/1，不会报错也不会算成 -1 天
- 边界处理：出生日期在未来 → 已活 0 天；超过预期寿命 → 100%，剩余 0
- 严格校验日期（`2020-02-30` 这种会被拒绝）
- 周格子：总周数 = ⌈总天数/7⌉，已过周数 = ⌊已活天数/7⌋，「此刻」那一格高亮呼吸
- 视觉零依赖，用 `radial-gradient` + 动画脉冲做氛围，无图片无字体外链

## 已知限制

- 预期寿命是一个整体数字，没有按地区/健康因素细分模型
- 「心跳 70 次/分」「呼吸 15 次/分」是粗略估算，只为制造体感，非医学数据
- 只支持公历；不处理农历生日
- 周格子最多渲染 5200 格（约 100 年），超过部分截断——130 岁预期下也一样能算数，只是不画完
