# 一命人生 · 随机人生模拟器

> 投一次胎，然后一年一年活过去，直到终点。看这一次拿到的是什么命。

## 解决什么问题

想体验「如果人生是另一种开局」这种好奇心。不是复盘人生，是**旁观一条陌生的人生**——
出身、天赋、机遇、婚姻、健康、财富都由随机数决定，每个选择带来的连锁反应也用规则表达。
没有正确答案，只有这一条命长什么样。

## 怎么玩

直接双击 `index.html`，或 `python3 -m http.server 8931` 后打开。

1. 点 **投胎** → 随机一个出身（城市/县城/山村/海外）+ 一个天赋（过目不忘/身体结实/大器晚成…）
2. 点 **过一年 →** 或按 **空格键**，一年一年推进；每年可能触发 0~2 个事件
3. 懒得逐个点就点 **快进十年**，或 **一生速览** 直接跑到底
4. 死亡后出现墓碑：人生称号、墓志铭、评分，以及一条 100 格的寿命刻度

同一个种子 = 同一条命，所以 UI 里显示的 `种子 #xxx` 可以复现；点「重新投胎」换一条。

## 实现要点

- **纯函数式人生引擎** `life-sim.js`：`createLife(seed)` → 逐年 `stepYear(s)` → `summarize(s)`。
  - 种子化随机（mulberry32），不依赖 `Math.random`，因此可在 Node 里批量跑 1000 条命做回归。
  - 浏览器 `<script src>` 与 Node `require` 双用（UMD 风格）。
- **事件系统**：每个事件声明 `age` 区间 + `cond(state)` 条件 + 权重；一年从符合条件的池子里按权重抽。
  - 事件可以带 `effect`（函数式，可依赖当前状态，比如「创业成功与否」当场掷骰）
  - 事件可以打 `flag`（`college` / `married` / `famous`）和 `kids`，影响后续整个事件池
  - 一次性事件通过 `flags['ev_<id>']` 锁死，避免「考了三次高考」
- **数值不封顶的反制**：45 岁后健康自然衰减、30 岁后魅力/财富缓慢衰减，防止属性一路冲到 100 让评分失真。
- **寿命模型**：`75 + floor(health/12)`，健康差的人可能中年就没了；健康归零则提前谢幕。
- **评分校准**：平均属性映射到 62 分 + 年龄/子女/婚姻/名气加分，再 clamp；实测 800+ 条命分数落在 40~110 区间。
- UI：零依赖原生 JS，日志按年份倒序追加 + 自动滚到底，空格键推进。

## 已知限制

- 事件大约 21 条，重玩多次后会看到重复；没有做「同一年事件去重剧情链」。
- 没有「难度」或「自定义出身」；人生不可交互干预（只能选快进/慢放），所以更像观众而非玩家。
- 墓志铭是从模板池里挑的，不是按人生轨迹生成的文案。
- 没有历史记录 / 分享图（懒得做 canvas 生成图，砍掉了）。

## 实测验证

- `node --check life-sim.js && node --check test.js` ✅
- `node test.js` — 14 项断言全绿：
  - 单人一生寿命在 30–110 区间、同年份日志年龄单调不减
  - 同种子结果完全一致，不同种子结果不同
  - 1000 条命批量跑：属性始终在 0–100 内，最长寿命 ≤ 115，平均寿命 76.9
  - 称号分布：稳稳当当 813 / 活得漂亮 130 / 寻常人家 57（1000 条样本）
  - 关键剧情出现率：大学 >30%、婚姻 >20%、生育 >15%
- 静态服务：`http.server` 探测 `index.html` 200、`life-sim.js` 200 ✅
