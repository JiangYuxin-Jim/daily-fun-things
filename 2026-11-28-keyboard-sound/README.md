# 键盘音效实验室 · keyboard-sound

## 解决什么问题

机械键盘的爽感不在于打字快，而在于**声音**。但好听的键盘要花钱，
而且不是每个人都敢在办公室/宿舍敲青轴。

这个小工具用 Web Audio 实时合成 7 种「敲击声」：换音色、调音量、升降调，
再配一排可视化声波柱和连击/KPM 统计 —— **你敲得越快，音高越往上飘**，
打到 30 连击还会爆一圈粒子。

零音频文件、零依赖、单个 HTML 打开就能用。

## 怎么玩

1. 直接双击 `index.html`（或 `python3 -m http.server` 起个本地服务，推荐 —— 浏览器对 `file://` 的音频策略更严）
2. 顶部选一个音色（打字机 / 麻将 thock / 青轴 / 气泡 / 激光 / 木鱼 / 老式空格）
3. **随便敲键盘**，或者在中间输入框里打字；也可以点下面的虚拟键盘
4. 中间那块会跳出五颜六色的声波柱 —— 空格键是蓝色，回车是粉色，连击升调后变橙色
5. 想听一段完整效果点「▶ 自动演奏一段」
6. 右下角可以调音量、开关连击升调、整体升降 12 个半音

## 实现要点

- **两层打击声**：每个音色拆成 `click`（高频瞬态 + 噪声）和 `tail`（低频闷响尾音），
  两个 `Oscillator + Gain(exp decay)` 叠加，噪声层走 `highpass` 滤波。这比单纯的正弦「哔」真实得多。
- **占空比扫频**：`frequency.exponentialRampToValueAtTime` 让频率在衰减期内滑到终点，
  例如激光是 2400Hz → 400Hz 的下坠，气泡是 420Hz → 1040Hz 的上滑。
- **键位感知**：`keyGroup()` 把按键分 6 组，空格 / 回车 / 退格 / 修饰键各带一个音高偏移，
  所以大键位听起来天生更低沉 —— 这是「像真键盘」的关键细节。
- **连击升调**：`ComboTracker` 用 420ms 窗口判连击，连击数越大 `paramsFor` 的 `factor` 越高（最多 +12%），
  于是快速连打会自然「飞起来」。
- **立体声**：click 稍偏右、tail 稍偏左，用 `StereoPannerNode`，一耳朵的宽度。
- **核心引擎独立**：`synth.js` 是 UMD 模块，浏览器和 Node 都能 require。
  Node 端它还能把参数渲染成 PCM 并导出 WAV（`render()` + `toWavBuffer()`），方便离线试听/调参。

## 已知限制

- 音色是**合成**的，追求「像」而不是「一模一样采样」，细节上不如真实录音（尤其机械弹簧的杂音）。
- 移动端没有物理键盘，只能点虚拟键盘，声音触发受系统音频策略影响（首次需点一下页面激活）。
- 需要浏览器支持 Web Audio（现代浏览器都行；Safari 需用户手势后才能出声）。
- 自动演奏只是随机序列模拟打字节奏，不是真正的「演奏」。
- 没做音效导出到浏览器端（导出 WAV 目前只在 Node 里）。

## 实测验证

```bash
node --check synth.js && node --check test.js
node test.js
```

```
[1] 预设清单           ✓ 7 个音色预设
[2] 参数映射确定性     ✓ 同种子同 factor；空格比普通键低沉 (0.688 < 1.008)；连击 24 提升 1.087 倍
[3] PCM 合成           ✓ 7 个预设 peak≈0.98、rms 0.08~0.18，全部有有效波形
[4] WAV 导出           ✓ RIFF/WAVE 头、尺寸字段、44100Hz，写出 samples/clack-demo.wav
[5] 节拍与 KPM         ✓ 连击超窗重置、最佳连击、KPM 计算
结果: 20 通过, 0 失败
```

- `samples/clack-demo.wav` 就是 Node 端合成出的青轴样本，可直接播放试听。
- 网页类验证：起本地 HTTP 服务探测 `/index.html` 与 `/synth.js` 均返回 **200**；
  页面内联脚本通过 `node --check` 语法检查。

## 文件

- `index.html` — 页面、虚拟键盘、可视化、Web Audio 播放
- `synth.js` — 音色预设 / 按键映射 / 连击判定 / PCM 合成 / WAV 导出（核心引擎）
- `test.js` — Node 自测（20 条断言）
- `samples/clack-demo.wav` — 合成样本
