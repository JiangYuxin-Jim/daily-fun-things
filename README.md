# daily-fun-things

每天一个小作品。可能是解决实际问题的实用小工具，也可能是让人会心一笑的小游戏，
甚至是一个奇奇怪怪但很好玩的创意实验。

每个项目一个独立文件夹，纯前端项目直接双击 `index.html` 就能跑，零依赖、零配置。

## 目录约定

```
    ├── dir.json     # 元信息（日期/名称/类型/技术栈）

```
