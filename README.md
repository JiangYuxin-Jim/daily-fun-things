# daily-fun-things

每天一个小作品。可能是解决实际问题的实用小工具，也可能是让人会心一笑的小游戏，
甚至是一个奇奇怪怪但很好玩的创意实验。

每个项目一个独立文件夹，纯前端项目直接双击 `index.html` 就能跑，零依赖、零配置。

## 作品索引

| 日期 | Day | 项目 | 一句话介绍 | 类型 | 技术栈 |
|---|---|---|---|---|---|
| 2026-10-30 | Day 00 | [文本手术刀 · txt-toolkit](./2026-10-30-txt-toolkit) | 一键清洗从 PDF/网页复制来的脏中文文本，顺带统计字数 | 工具 | HTML/JS |

> 完整 30 天清单见 [ROADMAP.md](./ROADMAP.md)

## 目录约定

```
daily-fun-things/
├── README.md
└── YYYY-MM-DD-项目名/
    ├── README.md    # 这个作品解决什么问题、怎么用
    ├── dir.json     # 元信息（日期/名称/类型/技术栈）
    └── index.html   # 入口（或 main.py 等）
```
